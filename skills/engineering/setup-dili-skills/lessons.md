# Lessons

A buffer of agent mistakes that may recur. An entry goes here before anyone fixes the cause. `/retro` reads this file, groups the entries, and proposes a check once one kind of mistake has three.

What belongs: a mistake a person, a check or a verifier had to catch, and that another run could make again. Code in the wrong layer. A banned pattern. A test that asserts the implementation. A domain term misread. A question the code already answered. The same INCONCLUSIVE for the same reason.

What stays out: product bugs (those go to the issue tracker), one-off slips, product decisions.
